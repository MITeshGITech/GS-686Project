# GS-686Project
Injection of CO2 changes the rock's fluid bulk modulus and rock bulk density. As such there is change in seismic velocity in the region. This phenomenon can be monitored to estimate the CO2 saturation. 
##Citation 
Time-lapse seismic inversion for CO2 saturation with SeisCO2Net: An application to Frio-II site
Zi Xian Leong, Tieyuan Zhu, Alexander Y. Sun
